# ======================================================================
#  لیست منابع وب برای رصد
#  هر خط:  حالت | لینک | (اختیاری) پارامتر
#
#  حالت‌ها:
#    page  → فقط همان یک صفحه خوانده می‌شود (دقیق و سبک) ← پیش‌فرض پیشنهادی
#    site  → کل سایت تا عمق مشخص خوانده می‌شود (سنگین‌تر)
#
#  مثال‌ها:
#    page | https://example.com/prices
#    site | https://competitor.com | depth=2
#
#  خطوطی که با # شروع می‌شوند نادیده گرفته می‌شوند.
#  محتوای تکراری خودکار حذف می‌شود؛ فقط مطالب «جدید/تغییرکرده» خروجی می‌گیرند.
# ======================================================================
